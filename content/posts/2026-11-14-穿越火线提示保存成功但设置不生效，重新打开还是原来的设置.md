## 问题描述

在《穿越火线》中修改设置（恢复默认、切换窗口/全屏模式等）并点击确定后，游戏内会提示已保存，但重新打开设置会发现修改并没有生效，设置又回到原来的状态。

本次故障的电脑只有一块硬盘、一个 C 盘，没有 D、E、F 分区；点击「文档」目录会直接报错，命令行窗口也无法正常打开。

## 问题原因

排查发现，注册表中记录「文档」目录位置的 `Personal` 项，被设置成了 D 盘上的一个目录。而本机只有一个 C 盘，这个路径实际不存在，穿越火线无法把设置写入文档目录，因此出现保存不生效的情况。

另外，通过 Windows 安全中心检查，发现电脑存在疑似中毒的迹象，系统时间也未正常同步。「文档」目录、命令行窗口打开报错等情况，也可能对设置的正常保存造成影响。

## 解决办法

### 一、排查系统环境

1. 打开 **Windows 安全中心**，检查电脑是否存在中毒迹象。本次检查发现有异常，因此执行了一次全盘杀毒扫描。

2. 用鼠标右键点击任务栏右下角的**时间**，选择「调整日期/时间」。在日期与时间设置中，把与时间相关的开关（自动设置时间、自动设置时区等）全部打开，确保三个开关都处于开启状态，最后点击「立即同步」，提示同步成功即可。

这两步虽然不是直接解决该问题的操作，但可能对设置的保存造成影响，所以先做一次排查。

### 二、新建用于保存设置的文件夹

1. 打开「此电脑」，进入 C 盘，新建一个文件夹，命名为 `CFData`。

2. 进入 `CFData`，再新建一个子文件夹，命名为 `CFSystem`，用于存放穿越火线的设置文件。最终路径为 `C:\CFData\CFSystem`。

### 三、修改注册表中的「文档」目录位置

1. 打开**任务管理器**，通过「运行新任务」打开运行窗口，输入 `cmd` 并点击确定。

2. 在命令行窗口中输入下面的命令，回车打开注册表编辑器：

   ```
   regedit
   ```

3. 定位到下面这个路径（也可以把路径直接粘贴到地址栏）：

   ```
   HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders
   ```

4. 在右侧找到 `Personal` 项，双击打开，可以看到它当前指向的是 D 盘的一个目录。

5. 由于本机只有一个 C 盘，这个路径肯定是错的，先把原有内容删除。

6. 在数值数据中填入 `C:\CFData`，点击确定。

   注意：`Personal` 指向的是 `CFSystem` 的上一级目录，也就是 `C:\CFData`，而不是 `CFSystem` 本身。这样游戏使用文档目录下的 `CFSystem` 时，实际路径就是 `C:\CFData\CFSystem`。

7. 点击右上角关闭注册表编辑器。

### 四、重启并验证

1. 重启电脑，其他设置不需要改动。

2. 开机后打开游戏进入设置，点击「恢复默认」，再点击「初始化」，画面会切换为全屏，点击确定后设置即可正常保存。

3. 重新打开设置，可以看到修改已经全部生效；退出游戏再进一次，再次打开设置确认依然正常。
