## 问题描述

一台安装 Windows 11 的电脑，连接惠普 HP LaserJet M1005 打印机后出现以下问题：

- Windows 能正常识别打印机。
- 打印文档和系统测试页均失败。
- 打印队列直接显示「错误」。
- 重启打印服务、清理打印缓存后仍无法打印。
- 尝试卸载驱动时，系统提示「驱动程序正在使用中」。

## 问题原因

排查发现，打印机驱动被现有的打印机队列占用，无法直接删除；同时打印任务无法正常写入缓存目录。

卸载旧驱动并重新安装官方驱动后打印恢复正常，但原始故障究竟来自驱动文件损坏、驱动配置异常，还是打印组件之间的兼容性问题，暂不能完全确认。

## 解决办法

### 一、查看打印错误日志

建议先查看日志，了解故障发生在哪个环节，避免盲目重装驱动。

1. 按 `Win + R`，输入 `eventvwr.msc`，打开事件查看器。

2. 依次展开：

   ```
   应用程序和服务日志 → Microsoft → Windows → PrintService → Admin / Operational
   ```

3. 检查 Admin（管理）和 Operational（操作）日志是否启用。如果显示未启用，右键选择「启用日志」。

4. 打开 Windows 设置，进入「蓝牙和其他设备 → 打印机和扫描仪」，选择 HP LaserJet M1005，打开「打印机属性」，点击「打印测试页」，重新触发一次故障。

5. 返回事件查看器刷新日志，分别选中 Admin 和 Operational，在右侧点击「将所有事件另存为」，保存为 `.evtx` 格式，用来分析错误代码、事件 ID、驱动异常和打印任务状态。

本次故障发现的错误包括：

- `0x80004005`：历史日志中的未指定错误。
- `0x2`：打印后台程序尝试删除 `.SHD` 文件时，找不到指定文件。
- 打印任务被创建并处理，随后被删除，但没有实际打印。

需要注意的是，这些日志只能辅助定位，不能单凭某一个错误代码确定根本原因。

### 二、重启打印后台服务

1. 按 `Win + R`，输入 `services.msc`。

2. 找到 **Print Spooler（打印后台处理程序）**，右键选择「重新启动」。

3. 再次打印测试页。

本次结果：无效。

### 三、清理打印缓存

1. 在 `services.msc` 中找到 Print Spooler，右键选择「停止」。

2. 打开文件资源管理器，进入：

   ```
   C:\Windows\System32\spool\PRINTERS
   ```

3. 删除文件夹内部的打印任务缓存文件，包括可能存在的 `.SPL` 和 `.SHD` 文件。

   注意：不要删除 `PRINTERS` 文件夹本身，清理操作会取消尚未完成的打印任务。

4. 返回服务管理器，启动 Print Spooler，然后重新测试打印。

本次结果：仍然无法打印。清理后发现打印任务无法正常写入缓存目录，曾尝试通过文件夹「属性 → 安全」调整权限，但没有解决问题。不建议将修改系统文件夹权限作为常规修复手段。

### 四、断开 USB 并删除打印机

1. 拔掉打印机与电脑连接的 USB 数据线。

2. 打开 Windows 设置，进入「蓝牙和其他设备 → 打印机和扫描仪」。

3. 找到 HP LaserJet M1005，点击「删除」。如果存在同型号的重复打印机，也一并清理。

本次结果：删除打印机后问题仍未解决。

### 五、卸载旧驱动

1. 按 `Win + R`，输入 `printui.exe /s /t2`，进入「打印服务器属性 → 驱动程序」。

2. 找到 HP LaserJet M1005，选择「删除」，尝试删除驱动程序及驱动程序包。

本次出现以下提示：

```
无法删除以下程序包：

hpljm1005.inf (x64)

该程序包具有以下正在使用的驱动程序：
HP LaserJet M1005

无法删除以下驱动程序：

驱动程序 HP LaserJet M1005 (x64)
正在使用中。
```

说明仍有打印机配置引用该驱动，需要先解除占用。

### 六、用 PowerShell 解除驱动占用

这是本次解决问题的关键步骤。右键 Windows 开始菜单，选择「终端（管理员）」，进入 PowerShell。

1. 查询驱动占用情况：

   ```powershell
   Get-Printer | Where-Object DriverName -eq "HP LaserJet M1005"
   ```

   查看哪些打印机队列仍然使用该驱动。

2. 确认查询结果均为需要删除的 M1005 打印机后，删除占用驱动的打印机队列：

   ```powershell
   Get-Printer | Where-Object DriverName -eq "HP LaserJet M1005" | Remove-Printer
   ```

3. 重启打印服务：

   ```powershell
   Restart-Service Spooler
   ```

4. 卸载旧驱动：

   ```powershell
   Remove-PrinterDriver -Name "HP LaserJet M1005"
   ```

   如果执行成功，说明对应的打印驱动已被移除。该命令删除打印驱动，不保证同时清除驱动存储中的所有安装包，如需清理残留程序包，可以重新打开 `printui.exe /s /t2` 检查。

以上命令只针对名称匹配的 HP LaserJet M1005 驱动，不要直接替换成其他打印机名称后批量执行。

### 七、重新安装官方驱动

1. 在惠普官网下载对应驱动，并核对系统兼容性：

   ```
   https://support.hp.com/cn-zh/drivers/hp-laserjet-m1000-multifunction-printer-series/model/1839459
   ```

2. 保持 USB 数据线断开，运行驱动安装程序。

3. 根据安装向导提示连接打印机，等待驱动安装完成。

4. 进入打印机属性，打印 Windows 测试页。

本次结果：重新安装驱动后，打印机恢复正常。
