## 问题描述

正常情况下打开拳头客户端（Riot Client）启动VALORANT时，按钮应显示为 **Play / 开始游戏**。但当前电脑打开后，按钮显示为 **Update / 更新**，点击后反复更新，陷入死循环，无法正常进入游戏。

Windows 安全中心存在红叉提示，部分安全服务未正常开启。

## 问题原因

- 排查发现 Windows 安全中心防火墙、病毒防护等服务状态异常，存在手动添加的不正规白名单条目（`D:\Steam`），可能影响反作弊（Vanguard）的正常校验
- 国服反作弊程序（ACE）与国际服环境冲突，干扰拳头客户端的更新检测
- 拳头客户端与 Vanguard 反作弊安装残留或损坏，导致客户端误判为需要更新
- 未排除中毒或恶意文件篡改系统环境的可能性

## 解决办法

### 一、排查 Windows 安全中心与系统环境

1. 打开 **Windows 安全中心**，检查所有带红叉的项目，全部开启（包括防火墙、实时保护等）；防火墙务必保持开启，关闭状态可能触发反作弊校验异常。

2. 进入 **病毒和威胁防护** → 查看 **保护历史记录**，排查近期是否有病毒、威胁或被阻止的操作记录。

3. 进入 **管理设置**，检查排除项（白名单）。若存在不明确的排除项（如本次排查发现的 `D:\Steam`），将其移除；正常使用无需手动添加此类排除项。

4. 执行一次 **全盘病毒扫描**，等待扫描完成；扫描结果通常有两种情况：确实干净，或有威胁但未被检出。后续步骤需结合扫描结果继续排查。

5. 打开 **设备安全性** → 进入 **内核隔离**，确认核心隔离相关开关已打开。

6. 右键开始菜单，选择 **终端(管理员)** 或 **命令提示符(管理员)**，输入：

   ```
   msinfo32
   ```

   回车打开「系统信息」，重点检查三项：
   - BIOS 版本与日期（若后续出现提示 BIOS 过旧，可考虑升级 BIOS）
   - BIOS 模式（UEFI 正常）
   - 安全启动状态（需为「已启用」）

7. 继续在管理员命令窗口输入：

   ```
   tpm.msc
   ```

   回车打开 TPM 管理，确认 TPM 2.0 已准备就绪并正常启用。

8. 若系统使用 **微软在线账户** 登录，进入 **设置 → 隐私和安全性 → 设备加密**，将「设备加密」开关关闭，避免后续操作将账户锁死在系统外。

### 二、彻底卸载相关程序并清理残留

9. 打开卸载工具（如 Geek Uninstaller），按以下顺序卸载：
   - 若电脑不玩国服游戏，先卸载 **ACE（国服反作弊）**；如仍需玩国服可跳过此步
   - 卸载 **Riot Client / 拳头客户端**
   - 卸载完成后执行卸载残留清理，清理注册表与安装目录残留文件

10. 手动检查反作弊安装目录，确认残留已清除：
    - 打开 `C:\Program Files\`，确认无 Vanguard / Riot Vanguard 相关文件夹
    - 打开 `C:\Program Files (x86)\`，同样确认无相关残留文件夹
    - 如上述位置均无对应目录，说明反作弊程序已无安装残留

### 三、重新安装拳头客户端与 VALORANT

11. 等待全盘病毒扫描完成，结果显示「未发现任何新威胁」后，开始重新安装。

12. 运行 VALORANT 安装包，选择安装路径：
    - 拳头客户端建议选择 **D 盘**（或非系统盘）
    - 后续安装 VALORANT 游戏本体时将默认使用同盘符，避免 C 盘空间不足（游戏本体约占用 30GB）

13. 点击 **Install** 开始安装，Vanguard 反作弊会随客户端一并安装。

14. 安装完成后首次启动拳头客户端，会提示 Vanguard 仅安装完成一半，**需要重启电脑**才能完成安装并生效。

15. 重启电脑后再次打开拳头客户端，按钮应恢复显示为 **Play / 开始游戏**，点击即可正常进入游戏。
