## 问题描述

英雄联盟体验服（PBE）启动或安装过程中出现异常，主要表现如下：

* 打开英雄联盟体验服时提示：

```
Riot Vanguard 是 Riot 的反作弊系统：以最高标准维护我们旗下游戏的竞技公正性。
```

反作弊程序无法正常安装，检查 `C:\Program Files` 目录后发现缺少正常情况下应存在的 Riot Vanguard 反作弊文件夹。

* 登录体验服时提示：

```
League of Legends 无法使用你的 PBE 账号游玩：请关闭所有执行中的游戏并更换账号。
```

提示当前账号无法用于 PBE 游戏，需要确认账号是否具备体验服资格。

* 启动游戏时提示：

```
This game is not yet available in your region.
```

提示当前地区无法使用该游戏服务。

* 英雄联盟客户端更新后问题仍然存在。
* 重新安装体验服后，出现游戏安装按钮灰色，无法安装英雄联盟或体验服的问题。
* 启动游戏时提示游戏未安装，启动按钮灰色，无法正常进入游戏。

## 问题原因

该问题可能由多个因素共同导致：

1. **账号资格问题**

   英雄联盟 PBE 体验服需要专门的 PBE 资格账号，普通英雄联盟账号无法直接登录体验服。

2. **Riot Vanguard 反作弊组件异常**

   Riot Vanguard 是英雄联盟使用的反作弊系统，如果安装失败、文件缺失或组件损坏，会导致游戏无法启动。

3. **地区限制问题**

   PBE 服务存在地区限制，客户端可能根据账号地区、网络环境判断当前区域不可用，从而出现：

   ```
   This game is not yet available in your region.
   ```

4. **客户端或游戏文件损坏**

   原有拳头客户端、英雄联盟本体或 PBE 文件损坏，可能导致客户端无法识别游戏安装状态。

5. **系统环境异常**

   系统文件损坏、时间同步异常等情况，可能影响 Riot 客户端验证和组件安装。

## 解决办法

1. 检查系统文件完整性：

   * 打开 C 盘属性。
   * 进入「工具」选项。
   * 点击「检查」并执行磁盘扫描。
   * 右键 Windows 开始菜单，选择「终端（管理员）」。
   * 输入：

   ```cmd
   sfc /scannow
   ```

   等待系统扫描修复完成。

2. 清理 Riot 客户端和英雄联盟文件：

   * 卸载 Riot 客户端。
   * 卸载英雄联盟相关程序。
   * 删除残留文件。
   * 检查：

   ```
   C:\Program Files
   ```

   确认 Riot Vanguard 文件夹是否存在。

   * 打开 Windows 安全中心。
   * 查看：

   ```
   病毒和威胁防护 → 保护历史记录
   ```

   如果存在病毒记录，执行全盘扫描。

3. 检查系统时间：

   * 打开日期和时间设置。
   * 开启自动设置时间。
   * 开启自动设置时区。
   * 检查时间服务器：

   ```
   time.windows.com
   ```

   * 点击「立即同步」。

4. 重新下载安装 PBE 客户端：

   * 前往英雄联盟 PBE 官网下载对应版本。
   * 下载完成后运行安装程序。
   * 完成客户端安装。

5. 使用加速器下载游戏：

   * 打开常用加速器。
   * 加速英雄联盟 PBE。
   * 点击游戏下载。
   * 选择安装路径。
   * 等待游戏下载完成。

6. 使用加速器启动游戏：

   * 后续启动 PBE 时，通过加速器启动。
   * 点击「启动游戏」。
   * 等待 Riot 客户端加载。
   * 使用拥有 PBE 资格的账号登录。

7. 如果仍提示账号或地区问题：

   * 确认当前登录账号是否为 PBE 资格账号。
   * 退出所有正在运行的 Riot 游戏进程。
   * 更换正确的 PBE 账号。
   * 确认网络环境符合 PBE 服务要求。
