# 需求定稿 v3（剪辑助手执行细则）

本文档是剪辑判断的完整规则书。执行语义分析（SKILL.md 工作流程第 3 步）时必须通读并遵守。

## 一、素材与产出

- 素材：电脑故障解决案例/教程视频，人脸、声音、电脑画面已合成为一个完整视频文件
- 输出：1080P MP4（烧录字幕）+ 外挂 SRT + 剪辑记录 MD + 口播文本 TXT，全部放入素材目录 `output/`
- 原始视频永不覆盖

## 二、重复内容判断（最核心）

**以讲话内容为唯一判断依据，画面重复不能单独作为删除依据。**

| 情况 | 处理方式 |
|---|---|
| 画面重复，讲话内容不同 | 保留 |
| 画面重复，但讲解了新知识 | 保留 |
| 讲话重复，画面也重复 | 删除前面的重复版本 |
| 前面说得不好，后面重新说了一遍 | 保留后面较好的版本 |
| 前后两段话高度相似 | 优先保留后面完整、准确的表达 |
| 前面有独有信息，后面没有重复 | 保留前面的独有信息 |

执行方法：
1. `analyze.py` 用文本相似度找出候选重复对（仅候选，不直接执行）
2. AI 必须亲自通读上下文做最终语义判断，逐对确认"删前留后"或"都保留"
3. 拿不准的一律保留（完整优先于短小）

## 三、语气词处理（分级，目标是自然）

- 连续讲话中偶尔出现的少量语气词（嗯/呃/啊/那个/就是）：**保留**
- 正常呼吸、自然停顿（< 1.5s）：**保留**
- 语气词前后停顿很长、中间无有效表达（如 "嗯……（停 3 秒）……呃"）：**删除**
- 明显重复、无意义的语气词（"呃呃呃"、"那个那个那个"）：**删除多余部分**

**不要把真人口播剪成机械朗读。**

## 四、静音处理

- 删除不必要的长时间静音（默认阈值：无有效画面信息且静音 > 3s，可缩短而非整段删）
- 缩短无意义等待（如等待窗口响应时的空白停顿）
- **保留**系统启动、软件安装、扫描、修复等有观看价值的过程画面，即使其中无人声
- 不要因为静音就直接删除整个片段

## 五、字幕与口播稿

- 自动生成中文字幕，时间轴准确
- **字体合规**：统一 `思源黑体`（Source Han Sans SC，SIL OFL 1.1 免费商用），禁用微软雅黑/等线等需授权字体；字体配置单点在 `scripts/fontcheck.py`，渲染时用 `fontsdir` 指向静态字重目录并做解析自检；中英双语、中文在上英文在下，各严格单行、全片无标点（见 SKILL.md 字幕规格）
- **术语校对**：按共享白名单 `.trae/skills/shared/terminology.md`（唯一真源，与字幕助手共用）校对
- 白字黑边、底部居中（见 ffmpeg-recipes.md）
- **AI 通读全文校对**：修正错别字，重点核对电脑专业术语（注册表、组策略、命令提示符、任务管理器、蓝屏、驱动程序、BIOS、安全模式等常见同音误写）
- 口播文本 = 最终保留内容的校对后纯文字，按自然段组织，不含时间戳

## 六、动效与转场

- 仅在删减造成的拼接点加 0.5s 叠化转场
- 章节切换可加轻微转场
- 不做局部放大、框选、箭头、文字标注
- 不过度使用动画特效；风格：自然口播、专业教程、简洁、有质感

## 七、背景音乐

- 固定文件：`D:\IT小章\bgm\mixkit-digital-clouds-175.mp3`（Mixkit Free License，不随仓库携带）
- 循环铺满全片（ffmpeg `-stream_loop -1` 硬循环）；音量很低，循环接缝基本不可闻；如需更平滑，选用本身循环友好的曲目
- 音量约为人声的 5%~10%，绝不能盖过人声
- 视频最后 3 秒音乐淡出

## 八、后台运行

- 渲染用后台任务执行，不占前台、不接管鼠标键盘
- 渲染速度不限制，正常全速
- 完成后通知用户并给出成品路径

## 九、剪辑记录格式

`xxx_剪辑记录.md` 每处删改一条：

```markdown
| 时间段 | 类型 | 处理 | 原因 |
|---|---|---|---|
| 02:13–02:41 | 重复表达 | 删除 | 与 05:02–05:36 内容重复，后者表述更完整 |
| 08:20–08:26 | 长静音 | 删除 | 无有效画面信息的空白停顿 |
| 12:05–12:07 | 语气词 | 删除 | 长停顿夹无效"呃"，无实际表达 |
| 15:30–16:10 | 静音但保留 | 保留 | 系统扫描修复过程，有观看价值 |
```
