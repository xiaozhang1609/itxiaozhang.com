## 问题描述

打开《VALORANT》国际服时出现反作弊错误提示：

```
VAN9003
This version of Vanguard requires UEFI secure boot to be enabled in order to play.
See the Vanguard notification center in the tray for more details
```

电脑无法正常进入游戏，Vanguard 反作弊系统提示需要开启 UEFI Secure Boot（安全启动）。

检查电脑系统信息：

* BIOS 模式：UEFI
* 安全启动状态：关闭
* TPM 2.0：正常
* 内核 DMA 保护：启用
* 内存完整性：正常开启

当前仅安全启动处于关闭状态，导致反作弊检测无法通过。

## 问题原因

《VALORANT》国际服使用的 Vanguard 反作弊系统要求电脑开启 UEFI Secure Boot（安全启动）。

当前电脑已经满足其他安全要求：

* 系统启动模式为 UEFI；
* TPM 2.0 工作正常；
* Windows 内核隔离相关设置正常；
* 内存完整性已开启。

但是 BIOS 中安全启动功能未开启，同时 BIOS 中部分安全启动相关设置需要调整：

* CSM（兼容支持模块）需要关闭；
* Secure Boot 需要设置为 Windows UEFI 模式；
* Secure Boot 模式需要设置为 Standard；
* CPU 虚拟化功能需要保持开启。

由于 Secure Boot 未满足 Vanguard 检测要求，因此出现 VAN9003 错误。

## 解决办法

1. 检查 Windows 安全功能：

   * 按 `Win + R`，输入：

     ```
     tpm.msc
     ```

   * 确认 TPM 2.0 状态正常。

   * 打开 Windows 安全中心：

     ```
     病毒和威胁防护
     → 设备安全性
     → 内核隔离
     ```

   * 确认内存完整性已开启。

2. 检查设备加密：

   * 如果系统使用微软在线账户登录，需要进入 Windows 设置关闭设备加密。
   * 避免修改 BIOS 后出现无法进入系统的问题。

3. 进入 BIOS：

   * 重启电脑进入 BIOS 设置。
   * 打开高级模式。

4. 检查 CPU 虚拟化设置：

   * 进入 CPU 设置。
   * 确认以下选项开启：

     ```
     VMX
     ```

     ```
     VT-D
     ```

5. 检查 TPM 固件设置：

   * 找到：

     ```
     PCH FW Configuration
     ```

   * 确认 TPM Firmware 处于开启状态。

6. 开启安全启动：

   * 进入启动（Boot）设置。

   * 找到：

     ```
     Secure Boot
     ```

   * 先确认：

     ```
     CSM
     ```

     设置为关闭。

   * 将安全启动系统类型修改为：

     ```
     Windows UEFI Mode
     ```

   * 将安全启动模式修改为：

     ```
     Standard
     ```

7. 保存 BIOS 设置并退出。

8. 电脑重新进入 Windows 后，检查系统信息：

   * 确认安全启动状态已经变为开启。

9. 重新启动《VALORANT》国际服客户端。

设置完成后，Vanguard 反作弊检测通过，游戏可以正常进入训练场和进行游戏。
