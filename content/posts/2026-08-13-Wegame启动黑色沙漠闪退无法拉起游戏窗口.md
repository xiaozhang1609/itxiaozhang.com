## 问题描述

通过 **WeGame** 启动《黑色沙漠》时出现以下问题：

点击"启动"后游戏直接闪退，WeGame 无法拉起游戏窗口，游戏窗口无法弹出。

事件查看器中看不到有用的相关报错信息。

电脑配置信息：
- CPU：AMD 锐龙 5 5600X
- 显卡：AMD Radeon RX 5700

## 问题原因

此类闪退且无明确报错的问题，通常与以下因素有关：

1. 系统运行库缺失或损坏。
2. DirectX 文件缺失或版本不匹配。
3. 显卡驱动配置异常或驱动版本问题。
4. 系统文件损坏或缺失。
5. 系统时间未同步，导致游戏或平台校验异常。
6. 系统区域设置或 Beta 版 Unicode 支持冲突。
7. 网络代理或自动脚本设置异常。
8. hosts 文件中存在异常条目，影响游戏或平台网络连接。

## 解决办法

### 一、准备工作：安装或修复运行库与 DirectX

1. 准备运行库整合包（可从微软官网下载对应运行库和 DirectX）。
2. 运行整合包或独立安装程序，点击 `Yes` 或确认，耐心等待安装或修复完成。

### 二、清洁安装显卡驱动

1. 双击打开显卡驱动安装程序，点击 `Yes` 确认解压。
2. 解压完成后，点击「高级」选项。
3. 勾选「恢复出厂设置」选项（执行清洁安装）。
4. 点击 `Accept and Install`，开始驱动安装，耐心等待安装完成。

### 三、并行操作：系统文件扫描

1. 在驱动安装过程中，可同时按 `Win + X`，以管理员身份打开命令提示符（或 Windows Terminal 终端）。
2. 输入以下命令执行系统文件扫描与修复：

   ```
   sfc /scannow
   ```

3. 等待扫描完成，不要中途关闭窗口。

### 四、同步系统时间

1. 右键点击右下角任务栏的时间区域，打开「调整时间设置」。
2. 确保以下三个开关全部为开启状态：
   - 自动设置时间
   - 自动设置时区
   - 自动调整夏令时
3. 点击「时区」下拉框检查服务器，确认时间服务器为默认的 `time.windows.com`；如不是，点击「恢复默认」。
4. 点击「立即同步」，完成时间同步。
5. 关闭设置页面。

### 五、调整系统区域设置

1. 等待系统文件扫描完成后，在命令提示符中输入：

   ```
   intl.cpl
   ```

   回车打开「区域」设置面板。
2. 切换到「管理」选项卡，点击「更改系统区域设置」。
3. 勾选「Beta 版：使用 Unicode UTF-8 提供全球语言支持」（`Beta: Use Unicode UTF-8 for worldwide language support`）。
4. 点击 `OK` 确认。
5. 系统提示需要重启时，点击「稍后重启」或对应确认；再次点击 `OK` 保存所有设置。

### 六、关闭代理与自动脚本设置

1. 仍在命令提示符窗口中输入：

   ```
   inetcpl.cpl
   ```

   回车打开「Internet 属性」面板。
2. 切换到「连接」选项卡，点击「局域网设置」。
3. 取消勾选「为 LAN 使用代理服务器」（若之前为 LAN 使用代理服务器）的勾选。
4. 点击 `OK` 确认，再次点击 `OK` 关闭 Internet 属性面板。

### 七、重启电脑

1. 等待显卡驱动安装完成，系统提示需要重启时，点击 `Restart` 重启电脑。

### 八、清理 hosts 文件

1. 系统重启完成后，打开文件资源管理器，依次进入以下路径：

   ```
   C:\Windows\System32\drivers\etc
   ```

2. 找到 `hosts` 文件，双击选择「记事本」方式打开。
3. 默认情况下，hosts 文件中的有效条目均已被注释。检查文件末尾是否存在未被注释的异常条目。
4. 如确认无实际用途的条目（建议修改前务必备份原文件，备份后，直接删除异常条目。
5. 按 `Ctrl + S` 保存修改，关闭记事本。
6. 再次重启电脑。

### 九、验证游戏启动

1. 电脑重启完成后，打开 WeGame 平台。
2. 正常情况下，直接启动《黑色沙漠》。
3. 若仍无法启动，可在 WeGame 中对游戏执行「修复」操作。
4. 启动过程按以上步骤逐一排查，执行到哪一步恢复正常，后续步骤即可不再执行。
