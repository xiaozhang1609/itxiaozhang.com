## 问题描述

启动《越来越黑暗》（Dark and Darker）时，游戏弹出安全提示：

> **為確保公平競爭，請啟用以下安全設置：HVCI。**

检查 Windows 安全中心后发现，“设备安全性 → 内核隔离 → 内存完整性（HVCI）”无法正常开启，并提示存在不兼容的驱动程序，例如 `ssudbus`、`ssudmdm` 等驱动，导致游戏无法通过安全检测。

## 问题原因

HVCI（内存完整性）是 Windows 的一项安全功能。当系统中存在不兼容的驱动程序时，Windows 会阻止启用 HVCI，因此《越来越黑暗》（Dark and Darker）的安全检测无法通过，并弹出要求启用 HVCI 的提示。

此外，可检查系统是否采用 UEFI 启动模式、安全启动是否已开启，以及 BIOS 版本是否过旧，确保满足 HVCI 的运行条件。

## 解决办法

1. 以管理员身份打开 PowerShell 或命令提示符。

2. 查询、停止并删除不兼容驱动服务（若提示服务不存在，可直接跳过）。

   ```plaintext
   sc query ssudbus
   sc stop ssudbus
   sc delete ssudbus

   sc query ssudmdm
   sc stop ssudmdm
   sc delete ssudmdm
   ```

3. 删除系统驱动仓库中的对应驱动包。

   ```plaintext
   pnputil /delete-driver oem44.inf /uninstall /force
   pnputil /delete-driver oem45.inf /uninstall /force
   ```

   如果实际环境中的 `oem44.inf`、`oem45.inf` 不一致，应以系统对应的驱动包编号为准。

4. 删除对应的驱动文件，可根据驱动文件名称进行搜索并删除相关文件。

5. 打开“Windows 安全中心 → 设备安全性 → 内核隔离”，重新扫描驱动兼容性。

6. 确认不再存在不兼容驱动后，启用“内存完整性（HVCI）”。

7. 按提示重启电脑，使设置生效。

8. 重启完成后再次启动《越来越黑暗》（Dark and Darker），确认不再出现“**為確保公平競爭，請啟用以下安全設置：HVCI**”提示，游戏即可正常进入。
